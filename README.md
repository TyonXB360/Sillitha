> **Personal Portfolio & Cross-Disciplinary Engineering Hub**

---

## 🚀 Live Demo & Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Navigate to `http://localhost:5173` in your browser.

### 3. Production Build & Preview
```bash
npm run build
npm run preview
```

## 🎨 Visual Design & Color Palette

- **Spider Web Silk:** Light to silver-grey stroke (`#888888` / `#CCCCCC` / `#CBD5E1`) with realistic catenary sag between spokes.
- **Center Spider Graphic:** Detailed, glowing porcelain-white arachnid texture with luminous highlights.
- **Interactive Action Elements:** Vibrant purple hue (`#5B50F6` / `#4F46E5`) for interactive nodes, pill CTAs (`LETS CONNECT`, `View Full Documentation`, `Subscribe`).
- **High Contrast Typography & Cards:** Crisp whites (`#FFFFFF`, `#F8FAFC`) and silver-greys (`#CBD5E1`, `#94A3B8`) on deep dark charcoal (`#0B0B0E`).
